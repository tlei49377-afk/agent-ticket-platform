# 智能外卖平台外部系统接入说明

## 平台定位

智能工单 Agent 平台负责工单、审批、知识库和运行审计。智能外卖平台是外部业务系统，负责订单、餐品、骑手和支付数据。两者保持独立部署，不共享数据库，也不把外卖业务代码复制进 Agent 项目。

## 查询能力

Agent 可以通过只读工具查询外卖订单状态、商品明细、配送进度、退款状态和商家信息。查询工具必须携带当前用户身份和工单编号，只返回处理工单所需的最小字段，不返回完整用户隐私数据。

## 写操作边界

取消订单、退款、补发优惠券等操作属于外部系统写操作。Agent 不能直接执行，必须先生成审批单，由有权限的员工审批后再通过受控接口调用外部系统。外部接口需要幂等键，避免重复退款或重复补偿。

## 故障降级

外卖平台不可用时，Agent 仍应支持工单查询、知识库检索和人工审批流程。外部查询失败时应明确告知用户“暂时无法获取订单实时状态”，并把工单转为处理中或已挂起，不得编造订单信息。
